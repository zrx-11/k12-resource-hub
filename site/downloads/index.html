下载指南

“能下载的先下载”不等于把 41GB 教材塞进 GitHub Pages。下面分三档：已经下载到工作区的、可以按需下载的、不适合托管的。

结论：开源数据和小型工具已经下载并部署；教材 PDF 因为体积与版权，只保留官方入口和下载工具链，不在本站托管；需要后端/数据库的项目（学之思、SmartKBS、wrong-notebook）只给部署说明和仓库链接。

三、三条教材下载路线

路线 A：官方平台，最稳。打开 basic.smartedu.cn/tchMaterial，按“学段—学科—版本—册次”找到教材，在线阅读或下载 PDF。人教社版本也可以在 jc.pep.com.cn 找。优点是正版、免费、版本清楚；缺点是部分教材只有在线阅读。

路线 B：tchMaterial-parser，批量。在本地运行工具，粘贴教材预览页 URL，批量下载并自动命名、加书签。适合老师一次拉齐一册。注意：仅限个人学习；无 Token 的回退下载方式不保证长期有效。

路线 C：ChinaTextbook，离线归档。适合已经有明确版本需求、能处理 35MB 分卷合并的人。不要一上来 clone 41GB；先看目录，只拉需要的年级/学科/版本。

版权提醒：教材 PDF 的版权归原出版社。官方平台与聚合仓库都限定个人学习使用；不要去除水印、二次售卖、打包卖“无水印版”，也不要把整册 PDF 直接放到公开站点。

五、本地下载建议

  • 先确认学校教材版本：人教/统编、北师大、苏教、浙教、沪教、外研、译林等。版本不对，下载再多也没用。
  • 一次只下一个学期、一个学科。PDF 命名成“版本-年级-册次-学科”，以后好找。
  • 重要教材至少留两份：官方平台下载一份，本地硬盘/网盘一份；不要只依赖一个链接。
  • 给孩子的设备只放当前学期内容；全量 41GB 放在电脑或移动硬盘，不要塞进手机。
  • 开源项目先看 LICENSE：MIT/BSD 可较自由使用；AGPL 商用要谨慎；CC BY-NC 不能商用。

下载指南是操作建议，不构成版权授权。具体资源能否下载、能否商用，以原站/原仓库的最新声明为准。
