关于与许可

这是一个个人非商业的中小学资源导航与轻量工具站。目的不是替代教材、学校或商业平台，而是把公开可用的入口、开源数据和可离线工具整理到一起。

本站与教育部、人民教育出版社、任何学校或商业机构没有隶属关系。资源链接、免费政策、授权协议都可能随原站调整；使用前请以原站最新说明为准。

本站的 知识图谱 是 xiaoyang111222/cn-math-taxonomy 的非商业镜像。原项目采用 CC BY-NC 4.0：可免费用于个人学习、教学、研究，可修改和再分发，但需署名并注明来源，不得用于付费课程、付费 App、机构收费服务或售卖题库等商业用途。

本站对原项目的改动仅限于：把静态文件放到本站子目录、调整部署路径、在页脚增加来源说明；未修改知识点、先修关系、题目与诊断算法。原项目的生产站点是 math.pansgo.com，如果镜像与上游不一致，以上游为准。

四、构建方式

本站是纯静态站点，由 GitHub Actions 构建并部署到 GitHub Pages。构建时才会拉取 chinese-poetry、hanzi-writer-data、pinyin-pro 与 cn-math-taxonomy 的公开数据；仓库本身不存放大体积第三方数据。

# 本地构建（需要 git / node / python3）
python3 scripts/prepare_assets.py
# 产物在 dist/，可直接用任意静态服务器打开
python3 -m http.server 8000 -d dist
